# Jerkgram M0.5-R2 + M1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Produce one Telegram iOS 12.9.4 test IPA with correct canonical Jerkgram Icon Composer branding and the first settings-only Jerkgram product foundation.

**Architecture:** Freeze the proven Telegram carrier and compatibility layer. Complete branding as a bundle-packaging pass derived from an Xcode 26 Icon Composer probe, checkpoint it, then rebuild only `Jerkgram.dylib` for a separated settings/store/localization/UI layer plus a narrow Telegram 12.9.4 Settings adapter.

**Tech Stack:** iOS 26/Xcode 26 GitHub Actions, Objective-C/C runtime integration where needed, Foundation/UIKit, Python 3 verifier/IPA tooling, plist/ZIP/Mach-O inspection.

**Spec:** `docs/superpowers/specs/2026-09-14-m05r2-m1-design.md`

## Global Constraints

- Carrier bundle ID stays `ph.telegra.Telegraph`.
- Main Telegram executable and all `JerkgramCompatibility.dylib` copies stay byte-identical through M0.5-R2 and the final IPA.
- M1 may rebuild `Jerkgram.dylib`; no other product feature behavior is implemented.
- Canonical Icon Composer source is `JerkgramGlassReveal.icon`; no preview-PNG rasterization.
- Canonical account key form is `jerkgram.account.<accountPeerId>.setting.<baseKey>`.
- `jerkgram.global.DownloadBoost` is global.
- English + Russian tweak-owned localization only for M1.
- About reports Jerkgram 1.0.2 / Telegram 12.9.4.
- Stop after combined M0.5-R2 + M1 artifact; do not begin M2.
