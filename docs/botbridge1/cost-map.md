## Mechanism classification

All new behavior is compiled source-native code. Request/lifecycle observation uses explicit existing call sites, not dynamic runtime interception. There is no new swizzling, reflection, global hook, dylib injector or periodic observer. Timers are limited to active history leases. Persistence is account-local Postbox progress plus asynchronous bounded dedicated diagnostics; Settings construction performs no diagnostic I/O. Modern outbound workers receive only explicit diagnostic context and preserve their algorithms through exact whole-file projection.

Bounds do not control allocation already performed by Network decoding. Transaction contention, actual material/GPU cost, server history coverage, FPS, heat, first/warm Settings latency and device crash behavior still require device measurements. Source/native fixtures and a GREEN IPA cannot establish Swiftgram parity. Deferred Wave1 findings D–H/S7 and automatic canonical archive cleanup remain outside this authorized implementation scope.
