## Protected modern paths

`MODERN-WRITE-BASELINE` fixes sixteen modern owners. Unchanged reaction/edit/delete/enqueue/conversion owners retain their hashes. For PendingMessageManager/StandaloneSendMessage, reversing only explicit context locals/arguments recovers the exact modern whole-file hashes. Network has an exact observer-removal projection retaining original parser, policy, dependency, callbacks and underlying disposable. The actual `.pollDifference` case and generic custom-operation body stay byte-identical. This is source proof, not execution of a whole sender or transport.
