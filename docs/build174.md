# Build174 — typing, continuous settings animation, bots and native local translation

Base: Official Telegram 13.1.1 fb0e62ba8a147f0821da6aa63c09da7d79a10111; parent Build173 a7f3a0415900c57e6d1ef389db916a9c99acbd05. Product 1.2.0 Beta 1, build174.

## Typing
The legacy composer synchronously receives its just-emitted input back through chat state, previously causing another model-to-display conversion and full three-round decoration pass. One-event provenance now bypasses only that duplicate content set. It requires the same editor, literal/semantic/display content, selection and render configuration; IME composition and external changes take the original path. Layout, accessories, undo and backend choice remain native. The guard has its own short-lived read/copy cost. This removes demonstrated repeated work, not a measured end-to-end latency result or proof of Swiftgram parity. Earlier comparison found most rich-editor code shared with Swiftgram; the user's exact installed beta remains unknown.

## Settings / profile
Descendant settings backgrounds subscribe to the original avatar player's frame stream and keep that native player alive only for visible descendants. There is no second decoder. Outputs detach on exit/suspension/source change; a visible page keeps a bounded player lease across app suspension to resume the same source. Main-thread secondary-layer disposal now finishes before rebinding, preventing a queued old detach from removing a new output. Root blur/tint/opacity are reused unchanged. Actual transition continuity remains a device check.

Metadata rows ID/DC/registration no longer copy on tap or hold itself. Hold opens the native localized Copy menu, and the explicit menu action copies. Native geometry/toast are retained.

## Bot accounts
Normal live replay now includes a chat only after a delivered cloud message is stored. It changes only an excluded inclusion state; existing archive group, pin and minTimestamp remain unchanged. The real own peer overrides the legacy bot marker where available. User-only getPeerDialogs/history work is gated for bots at metadata, validation, preload and low-level history boundaries without fabricating empty successful history or deleting stored messages. Supported live updates/update cursors remain intact. This repairs a source-backed visibility gap; device persistence across restart still needs checking and unseen old server history is not promised.

Ghost Mode is omitted for the logged-in bot account at both root and direct-page entry. Messages, save/show deleted and save/show edits remain available. Ordinary user settings remain unchanged.

## Translation architecture and gates
Reuse native TextProcessingScreen, Translate/Original/Copy/Apply/language selection, chat banner/state and TranslationMessageAttribute. Single-message and selected-composer input use the local adapter rather than the callback-dropping Apple sheet. Plain Translate skips cloud AI style bootstrap/notice/emojify; unrelated AI modes remain native. Whole-chat settings, banner and history gates add a narrow local capability, never fake account Premium. Show Translate and ignored-language preferences remain opt-in; entering a chat does not newly enable its translation.

On iOS18+, the existing Apple TranslationSession bridge is preferred. Each request uses its actual locally recognized source, not chat-majority language. Inputs to Apple are text plus opaque numerical correlation keys; account/peer/message ids remain in local bookkeeping. Models can require a system download. No new web service, API key or silent local-to-cloud fallback is introduced. Earlier supported behavior remains on older OS versions. Historical GitHub/local searches did not recover a separate older Jerkgram translator; this is not proof deleted refs never existed.

Native message text/captions/replies, poll question/options/solution and completed audio transcription use the local path. Rich InstantPage and unsupported media remain original and surface unavailable; no malformed rich content or original-as-success cache is created. Translated output entities are empty, so original offsets are never copied onto changed strings; original message semantics, copy/forward/reply remain untouched. Local rich formatting is not implemented in this bounded version.

The shared bridge permits one physical active batch, at most16 items /16KiB per request, total64 outstanding items /128KiB, and an LRU of256 completed items /1MiB including source/output bytes. Work dedupes by full source, languages and account-scoped local keys. Cancellation removes subscribers; the physical slot remains occupied until Apple's request returns. A single300-second logical timeout bounds UI waiting, including possible model download; it does not prove physical framework cancellation or stop a download. Retries wait for the real slot rather than start overlapping sessions.

Chat requests are owned by visible message/source snapshots. Target changes, source edits, offscreen exit and app suspension dispose requests; same-source work survives normal visible-range reconciliation. Local failures notify once per generation and have a15-second source-scoped cooldown, while independent successful messages finish. Poll/transcription source changes invalidate completed results too: persisted apple-v1 SHA256 fingerprints cover text/entities/poll structure/solution/audio/deletion state; vote counters are excluded. Native renderer/cache/scheduler checks reject stale content, including after reopen. A weak immutable-message validity cache avoids per-layout hashing and retaining old history.

## Localization
Recent profile, transparency, exclusion and translation strings use JerkgramStrings/current Telegram language, including ru-RU/ru_RU/-raw packs and English fallback. Ordinary backup labels/warnings/errors and Russian portable-reply help were corrected; Time Machine dates follow Telegram language. Central enum key coverage is complete in RU/EN. Hidden research diagnostic terminology was audited separately and not represented as fully localized ordinary UI.

## Verification / evidence limits
Exact staged parent/output hashes, ownership disjointness, reverse restoration, atomic unknown-input refusal and reapply refusal are checked before the full build. Existing icons, DownloadBoost, NoAds, retention and legacy source contracts are retained. Local integrated source tests pass. New real-production helper fixtures are authored for macOS CI: typing provenance, shared-player lease/lifetime and native secondary-layer dispose/rebind ordering, bot replay inclusion, bounded translation coordinator, source fingerprint/weak cache validity, selected-language strings. The fingerprint field-construction fixture uses a mocked Postbox encoder plus real SHA256; it is not a real Postbox roundtrip. Actual IPA compilation type-checks the full owners afterward.

This Linux host has no Swift/iOS compiler. Source-only checks are not compilation, runtime UI validation, native keyboard timings, bot durable-store proof, physical Apple cancellation or device TranslationSession/model validation. Fresh source review found and resolved source-edit scheduling and completed-result invalidation gaps; no actionable finding remained at review completion. CI/native and device results must be reported separately.
