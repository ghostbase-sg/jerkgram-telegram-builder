# Jerkgram Builder

Build and patch pipeline for Jerkgram on top of clean Official Telegram iOS sources.

This repository stores:
- Jerkgram source overlays and verifiers
- GitHub Actions workflows
- build and artifact helper scripts
- Jerkgram UI/icon assets

Legacy compatibility scripts may retain historical internal names until they are safely retired. New public-facing files, branches, workflows, artifacts, and features use the Jerkgram name.

Do not commit:
- .p12 certificates
- .mobileprovision profiles
- passwords
- signed IPA files
